# 유튜브 분석기

키워드와 최소 조회수로 유튜브 영상을 찾고, 고른 영상이 **왜 조회수가 많이 나왔는지** AI가 분석해 주는 Windows용 프로그램입니다.

- **검색:** 키워드로 검색해서 최소 조회수 이상인 영상만 조회수 순으로 보여줍니다.
- **분석:** 썸네일 이미지와 자막을 Claude가 읽고, 핵심 한 줄, 조회수가 나온 이유 TOP 3, 썸네일·제목·내용 점수, 썸네일 포인트, 내용 포인트, 따라 할 점, 내용 흐름을 한 화면에 보여줍니다.
- **보고서:** 분석한 영상들을 골라 HTML이나 Markdown 보고서로 내려받습니다.

## 필요한 것

- Windows 10/11
- Claude 구독(Pro 또는 Max) 계정. AI 분석은 [Claude Agent SDK](https://github.com/anthropics/claude-agent-sdk-python)로 하고, 구독 계정 로그인으로 인증합니다.

## 설치와 실행

아래 순서대로 한 번씩 더블클릭하세요.

1. `설치.bat`: Python 3.12(없으면 설치)와 필요한 패키지를 설치합니다. 설치 파일은 `C:\Users\사용자이름\.youtube-analyzer`에 만들어집니다.
2. `로그인.bat`: Claude 구독 계정으로 로그인합니다. 브라우저에서 로그인한 뒤, 화면에 나온 코드를 창에 붙여넣으세요.
3. `실행.bat`: 분석기가 켜지고 브라우저에서 `http://127.0.0.1:5000`이 열립니다.

그다음부터는 `실행.bat`만 실행하면 됩니다.

## 알아두면 좋은 점

- 각자 **본인의 Claude 구독 계정**으로 로그인해서 개인용으로 쓰는 프로그램입니다. 여러 사람이 쓰는 서비스로 만들려면 API 키 방식으로 바꿔야 합니다.
- 검색이나 자막 가져오기가 안 되면 `설치.bat`을 다시 실행하세요. [yt-dlp](https://github.com/yt-dlp/yt-dlp)가 최신 버전으로 올라갑니다.
- 분석 결과는 `results` 폴더에 저장되고, 같은 영상은 저장된 결과를 다시 보여줍니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `youtube.py` | yt-dlp로 검색, 영상 정보, 자막, 썸네일 가져오기 |
| `analyzer.py` | Claude Agent SDK로 분석 |
| `report.py` | 분석 결과 저장과 보고서 만들기 |
| `app.py` | 웹 서버 (Flask) |
| `templates/`, `static/` | 화면 |
| `scripts/` | 설치·로그인·실행 스크립트 |
